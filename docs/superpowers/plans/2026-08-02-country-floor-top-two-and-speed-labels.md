# Country Floor Top-Two and Speed Labels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the seven-country download floors, protect each configured country's fastest two valid unique IPs, and replace source text in final city labels with one-decimal measured speed.

**Architecture:** Keep configuration parsing and final CSV merging in the existing Windows PowerShell and Linux awk pipelines. Move country-floor decisions after best-measurement deduplication, rank within country by raw MB/s, protect up to two rows, then filter only later rows; format the final label from the retained row's parsed speed.

**Tech Stack:** PowerShell 5.1, Bash, awk, CFST CSV, repository script test harnesses.

## Global Constraints

- Defaults are exactly `JP=10,US=5,KR=3,HK=2,DE=5,GB=3,SG=5` MB/s.
- Equality with a floor passes.
- Each configured country protects its fastest two otherwise-valid unique IPs; with zero or one available, emit only those available.
- Old and new IPs compete only on current measured speed.
- Final city labels use `CC [LOCATION#NN 13.1MB/s]` and never expose source.
- CFST remains serial by default with `-t 2 -dn 10 -dt 4`.
- The result CSV must be generated by the full runner, never appended or manually row-edited.
